APPROACH: I treated this as an acquisition due-diligence exercise: (1) pull the raw vendor list, (2) classify every vendor with Claude Code, (3) validate the output with scripted checks, (4) aggregate spend by category to find where the money concentrates, (5) size the top savings levers with explicit assumptions, (6) write the CEO/CFO memo from those numbers. Spend is highly concentrated: 1 vendor (Salesforce) = 40%, the top 20 vendors = ~75%, while 208 small vendors = ~11%. I therefore spent analysis time on the top of the list and handled the long tail with policy-level actions.

TOOLS: Claude Code (Anthropic's agentic coding tool, run in the Claude desktop app's Code tab) for classification, scripting and drafting; Python 3 + openpyxl for data extraction, QA and writing the workbook; Google Sheets for the final deliverable. All files (inputs, scripts, outputs, README) are in the project folder.

PROMPTS: (1) "Read the assessment instructions and download the vendor spreadsheet." (2) "For each of the 386 vendors, assign one department from the Config tab list, write a specific one-line description of what the vendor does (no generic 'business services provider'), choose Terminate / Consolidate / Optimize, tag a spend category, and rate your confidence High / Medium / Low where the vendor identity is uncertain." (3) "Write a Python QA script that checks coverage, valid values, description quality and reconciles total spend to the source." (4) "Aggregate spend by category and propose the three highest-impact savings opportunities with explicit, conservative savings assumptions." (5) "Draft a one-page memo for the CEO and CFO with findings, savings, timeline, implementation steps and risks."

CLASSIFICATION RULES: Optimize = needed vendor with a price/usage lever (e.g. Salesforce, AWS, insurance, payroll). Consolidate = several vendors doing the same job (11 audit/tax firms, 13 law firms, 11 telecom carriers, 11 office providers, 2 Navan entities, 2 AWS entities, HubSpot vs Salesforce, Trello/Smartsheet/Aha!, Zapier vs Workato, Cognism/Lusha/6sense). Terminate = one-off or non-essential spend (M&A deal advisors post-close, restaurants, events, gifts, hotels booked outside Navan, individuals paid directly).

VALIDATION AND QUALITY CHECKS (evidence in output/qa_report.txt): (a) Coverage - 386 of 386 vendors classified, no missing or extra rows. (b) Allowed values - every department is from the Config list and every action is one of the three options; 0 violations. (c) Description quality - every description is 15-160 characters and none is generic; 0 violations. (d) Reconciliation - classified spend $7,887,360.40 equals source spend exactly. (e) Row alignment - the build script asserts each vendor name matches its source row before writing. (f) Confidence flag - 234 vendors High, 90 Medium, 62 Low; the Low-confidence vendors are all small (combined $235K, 3% of spend) and mostly Croatian sole traders whose name does not reveal the service, so they are marked for confirmation with AP before action. (g) Manual spot-check of the top 30 vendors by spend (~80% of total), where an error would matter most.

SAVINGS MODEL (output/savings_model.txt): Savings % assumptions are deliberately conservative and applied to category totals - Salesforce licences 25%, Salesforce consulting 40%, office space 50%, audit/tax 30%, deal advisory 100% run-off, ad-hoc consultants 60%. Top 3 = ~$1.9M (24% of spend). Additional travel and tail-spend savings of ~$0.18M are noted but excluded from the Top 3.

LIMITATIONS: Vendor descriptions are inferred from the vendor name and public knowledge, not contracts or invoices; savings require contract review (term dates, notice periods, renewal clauses) before being committed.
